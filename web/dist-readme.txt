HOW TO START
------------
  Mac:      double-click   "Start FLUX Studio.command"
  Windows:  double-click   "Start FLUX Studio.bat"

  Mac, first time only: if it says the file can't be opened, right-click it,
  choose Open, then click Open again.

Your browser opens FLUX Studio. The first time, you'll choose where to save your
images (default: a "FLUX Studio" folder inside Downloads) and paste your Black
Forest Labs API key. After that it remembers both.

To stop FLUX Studio, close the window the launcher opened.

NO ADMIN RIGHTS OR INSTALLATION NEEDED
--------------------------------------
The first launch downloads what it needs (about 40 MB, so you need internet once)
and keeps it inside the "app" folder. Nothing is installed on your computer.

UPDATING
--------
Download the newer zip and replace this whole folder. Your API keys, history and
settings are stored on your computer outside this folder, so nothing is lost.
(Mac: ~/Library/Application Support/FLUX Studio Web  -  Windows: %APPDATA%\FLUX Studio Web)

PRIVACY
-------
FLUX Studio runs only on your own computer and can't be reached from other devices.
Your API keys are saved as plain text readable only by your user account, so don't
share that folder.
