Welcome to FLUX Studio Web

Two minutes, one time. After that, it opens like any other app.

 I'm on a Mac
  1. 1

    Open Terminal

    Press ⌘ + Space, type Terminal, and press Return. A window with a blinking cursor opens. It is a normal Mac app that is already on your computer.

  2. 2

    Copy this line

    It already points at this exact folder. Click the line to select it, or use the button.

  3. 2

    Type bash and one space

    Do not press Return yet. Then drag the file Start FLUX Studio.command (it is in the same folder as this page) into the Terminal window.

  4. 3

    Press Return

    Click in the Terminal window, paste with ⌘ + V, then press Return. FLUX Studio opens in your browser. The first time it downloads what it needs (about 40 MB), so give it a minute.

From now on: just double-click Start FLUX Studio.command. You will not need Terminal again.
Why can't I just double-click it the first time?

macOS marks anything downloaded from the internet. For a file like this it then asks for an administrator's password before opening it, and most people on a work computer do not have one. Starting it from Terminal skips that check. The launcher then clears the mark from its own folder, which is why double-clicking works afterwards. If you are an administrator you can also double-click it and approve it in System Settings › Privacy & Security › Open Anyway.

Terminal says "No such file or directory"

The folder was moved or renamed after this page was opened. Close this page, open START HERE.html again from the folder's current location, and copy the line again. Or use the drag method: type bash, a space, and drag Start FLUX Studio.command into the window.

Nothing opened in my browser

Wait up to a minute the first time while it downloads what it needs, and keep an eye on the Terminal window. If it shows an error, send a screenshot of the Terminal window to whoever shared this with you.

  2. 2

    If Windows says it "protected your PC"

    Click More info, then Run anyway. No administrator password is needed. The first time it downloads what it needs (about 40 MB), so give it a minute.

Good to know

Is this safe?

FLUX Studio runs only on your own computer and cannot be reached from other devices. The first launch downloads a private copy of Node.js from nodejs.org (checked against its published checksum) and a few packages, and keeps them inside the app folder here. Nothing is installed on your computer, and you can read every file in that folder.

How do I stop it?

Close the Terminal window (Mac) or the black window that opened (Windows).

Where are my images and my API key kept?

The first time you start it you choose where images are saved (by default a FLUX Studio folder inside Downloads) and paste your Black Forest Labs API key. Your key and history are saved on this computer, outside this folder, so updating to a newer version never loses them. The key is stored as plain text that only your own user account can read, so do not share that folder.
